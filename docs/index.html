pixbot — abridores de app

Páginas de uma linha só. O Telegram só aceita http(s) e tg:// num botão — manda um santanderpf:// e a API responde “Unsupported URL protocol” e se recusa a enviar a mensagem. Alguns bancos brasileiros não publicam nenhum universal link, e o esquema próprio é a única porta que abre o app.

Então o botão aponta pra cá, e daqui o telefone abre o app:

  • santander.html

Nenhum dado de pagamento passa por estas páginas. O código Pix é gerado dentro do bot e vai direto pra área de transferência; não entra no endereço, não é enviado pra cá e não fica guardado em lugar nenhum. Estas páginas são estáticas e não têm servidor atrás.

Código: github.com/ogescalante/pixbot
